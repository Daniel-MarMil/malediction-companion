# ADR-08: Apache 2.0 license and allowed dependencies

- **Status:** Accepted
- **Date:** 2026-11-07
- **Reference:** section 10 of the architecture and requirements document

## Context

The project must be free software under the Apache 2.0 license and be distributed in the app stores without license conflicts.

## Decision

All our own code, the server included, is under Apache 2.0. Allowed dependencies: MIT, BSD, Apache, ISC, BSL, zlib and public domain; nothing GPL, LGPL or AGPL inside the apps or the server. This is checked with ScanCode, the vcpkg SBOM and the Gradle and Swift Package Manager lock files.

## Rejected alternatives

- Allowing LGPL dependencies: they require allowing relinking, which is disputed on iOS.

## Consequences

- Current dependencies: libsodium (ISC) and nlohmann/json (MIT); GoogleTest (BSD-3-Clause) and RapidCheck (BSD-2-Clause) only in the tests.
- Every file carries its SPDX header, and `tools/ci/check_licenses.py` checks it.
- GPL development tools (gdb, Valgrind, cppcheck) do not change the license because they are not distributed.
- vcpkg build tools that are not distributed, such as `vcpkg-make` (MIT and GPL-2.0-or-later, a host dependency of libsodium), are listed by name in `BUILD_TOOLS` in `tools/ci/check_licenses.py` after a review by hand; the check fails again if their copyright file changes.
