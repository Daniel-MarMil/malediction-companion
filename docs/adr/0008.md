# ADR-08: Licencia Apache 2.0 y dependencias permitidas

- **Estado:** Propuesta
- **Fecha:** 2026-11-07
- **Referencia:** apartado 10 del documento de arquitectura y requisitos

## Contexto

El proyecto debe ser software libre con licencia Apache 2.0 y distribuirse en las tiendas sin conflictos de licencia.

## Decisión

Todo el código propio, servidor incluido, va bajo Apache 2.0. Dependencias permitidas: MIT, BSD, Apache, ISC, BSL, zlib y dominio público; nada GPL, LGPL ni AGPL dentro de las apps o del servidor. Se comprueba con ScanCode, el SBOM de vcpkg y los ficheros de bloqueo de Gradle y Swift Package Manager.

## Alternativas descartadas

- Admitir dependencias LGPL: obligan a permitir reenlazarlas, algo discutido en iOS.

## Consecuencias

- Dependencias actuales: libsodium (ISC) y nlohmann/json (MIT); GoogleTest (BSD-3-Clause) y RapidCheck (BSD-2-Clause) solo en las pruebas.
- Cada fichero lleva su cabecera SPDX y `tools/ci/check_licenses.py` lo comprueba.
- Las herramientas GPL de desarrollo (gdb, Valgrind, cppcheck) no cambian la licencia porque no se distribuyen.
