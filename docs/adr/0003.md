# ADR-03: Servidor como monolito modular en C++20 con Drogon y PostgreSQL

- **Estado:** Propuesta
- **Fecha:** 2026-11-07
- **Referencia:** apartado 10 del documento de arquitectura y requisitos

## Contexto

El servidor coordina las partidas en línea y guarda cuentas e historial. Comparte el núcleo con las apps y el equipo es pequeño.

## Decisión

Un único servicio en C++20 con Drogon (MIT), dividido en módulos internos, y PostgreSQL como base de datos.

## Alternativas descartadas

- Boost.Beast: de más bajo nivel, con más código propio.
- Microservicios: demasiada operación para el tamaño del equipo.
- Firebase: aloja datos fuera del EEE (ADR-07).

## Consecuencias

- El servidor reutiliza el núcleo sin capas de traducción.
- Se decidirá al empezar la fase de partida en línea.
