# ADR-12: Official content in a private pack, separate from the code

- **Status:** Accepted
- **Date:** 2026-11-07
- **Revision:** 2026-11-13: the app receives the official pack from the server (ADR-13); the official pack importer
- **Reference:** section 10 of the architecture and requirements document

## Context

ADR-09 allows developing with the official content, but the repository is public and its license is Apache 2.0. Codeberg only allows private content that serves free software projects.

## Decision

The official content goes in a private pack, separate from the code, in `content/official/`, which git ignores. It goes neither to the public repository nor to Codeberg. The app receives it from the server as signed data (ADR-06 and ADR-13).

The pack is built on the development machine with the importer in `tools/content/` (2026-11-13):
only code goes into the repository. It reads the public pages of the malediction.gg card library
(robots.txt, `card-sitemap.xml`, each `/card/<slug>/` page and its image), never its REST API,
`admin-ajax` or anything that needs a session, one request at a time with at least 2 seconds
between them. It stops on 401 or 403, waits for Retry-After once on 429 or 5xx, and only downloads
again what changed according to the sitemap. Its cache lives outside the repository
(`~/.cache/seekers-companion/content/`), and it writes the pack, its images and the card ids to
`content/official/`. Its tests use made-up pages with the same shape. The pack is then signed by
hand with `mc_pack_tool sign`; the secret key never leaves the development machine.

## Rejected alternatives

- Keeping it in the repository: it would distribute the content without permission and mix licenses.
- A private repository on Codeberg: Codeberg only allows private content that serves free software projects.

## Consequences

- The repository only holds Apache 2.0 code and made-up test cards (`content/test/`).
- Continuous integration tests with the made-up pack, never with the official one.
- Until there is a license, the server that serves the official pack is private: only development and test accounts use it.
- Nothing downloaded from malediction.gg goes into commits, fixtures, examples or logs.
- `content/official/card-ids.json` must be kept with the pack: without it the ids could change,
  so the importer refuses to overwrite a pack when it is missing.
- Where to keep a backup of the private pack is still to be decided.
