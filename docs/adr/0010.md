# ADR-10: CMake y vcpkg en modo manifiesto con versiones fijadas

- **Estado:** Propuesta
- **Fecha:** 2026-11-07
- **Referencia:** apartado 10 del documento de arquitectura y requisitos

## Contexto

El núcleo se compila para Linux, Windows, Android e iOS y sus dependencias deben ser reproducibles.

## Decisión

CMake con presets y vcpkg en modo manifiesto con `builtin-baseline` fijo. Gradle y Xcode integran el núcleo ya compilado en cada app.

## Alternativas descartadas

- Conan: también libre y válido.
- Bazel: más complejo para un equipo pequeño.

## Consecuencias

- La línea base actual (vcpkg 6fdd23fa, 07-11-2026) resuelve GoogleTest 1.18.0, libsodium 1.0.22, nlohmann/json 3.12.0 y RapidCheck 2023-12-14.
- El preset `system` compila con las bibliotecas del sistema en Linux, sin vcpkg.
- vcpkg compila libsodium con autotools fuera de Windows: el sistema necesita autoconf, automake y libtool.
