# ADR-10: CMake and vcpkg in manifest mode with pinned versions

- **Status:** Accepted
- **Date:** 2026-11-07
- **Reference:** section 10 of the architecture and requirements document

## Context

The core is built for Linux, Windows, Android and iOS, and its dependencies must be reproducible.

## Decision

CMake with presets, and vcpkg in manifest mode with a fixed `builtin-baseline`. Gradle and Xcode integrate the prebuilt core into each app.

## Rejected alternatives

- Conan: also free and valid.
- Bazel: more complex for a small team.

## Consequences

- The current baseline (vcpkg 6fdd23fa, 2026-11-07) resolves GoogleTest 1.18.0, libsodium 1.0.22, nlohmann/json 3.12.0 and RapidCheck 2023-12-14.
- The `system` preset builds with the system libraries on Linux, without vcpkg.
- vcpkg builds libsodium with autotools outside Windows: the system needs autoconf, automake and libtool.
