# ADR-06: Reglas y cartas como paquetes de datos firmados con Ed25519

- **Estado:** Aceptada
- **Fecha:** 2026-11-07
- **Referencia:** apartado 10 del documento de arquitectura y requisitos

## Contexto

El reglamento de Malediction recibe erratas y revisiones. Publicar la app por cada cambio de reglas sería lento, y un paquete manipulado no debe aceptarse.

## Decisión

Las reglas y las cartas viajan como paquetes de datos versionados (formato `mc-rules-pack`) con una firma Ed25519 separada que se comprueba con libsodium.

## Alternativas descartadas

- Reglas en el código: obligan a publicar la app con cada errata.

## Consecuencias

- Fase 0: el núcleo lee el formato 1 (`RulesPack::parse`) y comprueba firmas (`mc_pack_verify`).
- Los límites de mazo y de copias vienen del paquete, no del código.
- Falta una herramienta para firmar paquetes y la gestión de claves.
